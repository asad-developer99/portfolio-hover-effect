# Portfolio Hover Effect

> An interactive hover/reveal effect for portfolio grid items, built with GSAP and ScrollTrigger.

![GSAP](https://img.shields.io/badge/GSAP-88CE02?style=flat-square&logo=greensock&logoColor=black) ![ScrollTrigger](https://img.shields.io/badge/GSAP_ScrollTrigger-88CE02?style=flat-square) ![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat-square&logo=html5&logoColor=white) ![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat-square&logo=css3&logoColor=white) ![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat-square&logo=javascript&logoColor=black)

## Overview

A reusable UI component demo for portfolio or work-index pages.

This project is part of a collection of front-end animation and interaction studies exploring modern scroll effects, transitions, and micro-interactions with GSAP and related libraries.

## Built With

- GSAP
- ScrollTrigger
- HTML5 & CSS3

## Getting Started

No build step required — this is a static HTML/CSS/JS project that loads its libraries from a CDN.

```bash
# Clone the repository
git clone https://github.com/asad-developer99/portfolio-hover-effect.git
cd portfolio-hover-effect
```

Then simply open `index.html` in your browser, or serve it locally for the best experience (recommended, since some browsers restrict local file access):

```bash
# using the VS Code "Live Server" extension, or:
npx serve .
```
